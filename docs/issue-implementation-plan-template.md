# Issue 実装方針テンプレート

GitHub Issue に実装方針を書くときは、必要に応じて以下を使う。
長すぎる場合は不要な見出しを削ってよい。

```md
## 実装方針

### 目的
- この Issue で解決したいこと

### スコープ
- この Issue で対応する内容

### 非スコープ
- 今回はやらない内容

### 方針
- どのレイヤーをどう変えるか
- 既存実装のどこを再利用するか
- 判定ルールや分岐条件があれば明記する

### 変更対象
- 変更予定の主要ファイルやディレクトリ

### 確認方法
- 実装後に回す format / lint / test
- 必要な手動確認

### リスク
- 想定される回帰や難所

### 未解決事項
- 実装前にまだ決めきれていない点
```

短く済ませたい場合の最小版:

```md
## 実装方針
- 目的:
- スコープ:
- 方針:
- 確認方法:
- 未解決事項:
```
